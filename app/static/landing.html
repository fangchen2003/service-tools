示例：柏宝绘

  1. 打开「渠道」→「配置」
  2. 点击「新建接入点」
  3. 「接口地址」填写上方地址
  4. 「API Key」填写你的 Key

任何支持自定义 NovelAI 地址的客户端都可以按同样方式填写。

使用须知

请仔细阅读以下规范，合理使用公益资源，避免被限流或封禁。

  • 客户端怎么填：生图客户端（Aaalice 启动器 / 酒馆 SillyTavern / DSH 插件 / 柏宝绘 / 智绘姬 等）接口地址填 —（末尾不要加 /v1），API Key 填你领到的专属 Key。
  • 出图模型规格：推荐 V4.5 Full 与极速 V5 Full（V5 仅需 4~5 秒完成出图，适合找灵感与快速 Roll 图）。免费尺寸上限 1024×1024 或等总像素（如 832×1216），步数建议 ≤ 28。图生图等付费功能未开通前请在客户端关闭。
  • 一次一张，别狂重试：单并发控制，每把 Key 同时只排队或生成 1 张，出完再发下一张。如遇排队请耐心等待——1 小时内连续被拒 60 次会自动触发 1 小时安全冷却，到点自动恢复。
  • 查额度、自助换 Key：在 Discord 输入 /quota 随时查看今日剩余免费额度与状态；若怀疑 Key 泄露或遇到配置异常，在 Discord 输入 /resetkey 可一键自助更换新 Key。
  • 一人一把，严禁转售与共用：公益资源有限，Key 仅限本人使用（挂梯子换节点、手机电脑多设备正常使用完全不受影响；但多人同时共用或转售会被系统拦截并回收）。退出 Discord 服务器或长期闲置后 Key 会被自动回收（连续 天不用）。
  • 合规安全，禁止违禁：严禁生成违反法律法规或极端有害的内容，违规账号将被永久封禁并不再恢复。
