如何领取或找回 Key？

在本站 Discord 服务器使用 /register 申请（以当时开放状态及资格要求为准），Key 仅通过私信发送。已有 Key 或因连续 3 天未使用而被回收，可使用 /find 找回。请允许机器人私信，不要在公开频道粘贴 Key。

  1. 01

    用本站 Key 登录，不是你的 NovelAI 账号

    进入仿 NovelAI 工作台，填写私信中收到的 nai-… Key。首次进入请按工作台提示设置连接；第三方客户端的 API 地址使用本站域名。请勿分享 Key，多人共用会共用额度。

  2. 02

    个人有上限，全站也有共享额度

    普通 Key 默认每日 V5 — 单位、V4.5 及以下 — 张，具体以你的 Key 为准。北京时间零点重置；/charge 每天可恢复一次个人生图额度，不增加全站额度。V5 还受官方账号可用额度影响。

  3. 03

    仅开放免费规格，不会自动转付费

    超出免费条件的尺寸、步数等会自动调整；无法安全转换的图生图、局部重绘、精确参考等不开放。开启自动节省且共享额度不足时，V5 Full 可能切至 Medium；自定义负面词不生效，按最终档位计量。

  4. 04

    耐心等队列，也给创作留一点隐私

    同一 Key 的任务会排队，请勿反复点击生成。/vibe 每日可领取 3 次编码机会，次日需重新领取。本站不保存新生成图片或提示词，会记录用量日志；请及时保存作品。连续 3 天未使用的普通 Key 会被回收。
